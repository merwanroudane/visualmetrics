# Contributing

The full guide lives in
[CONTRIBUTING.md](https://github.com/merwanroudane/visualmetrics/blob/main/CONTRIBUTING.md)
in the repository. The essentials:

## The rules that are not negotiable

1. **A simulation is never a proof.**
2. **Every proof states what it does not establish.**
3. **Every animation frame explains itself.**
4. **The catalogue never overstates itself** - unbuilt means marked, listed and
   refusing to open.
5. **Canonical scientific names only** - no local course labels in the API or
   the interface.
6. **Numerics are tested against theory** - a closed form, an exact identity or
   a known statistical property, never against last week's output.

Each of these is enforced by a test, not by review alone.

## Where help is most useful

- **Translating a lab.** About 2,400 `labs.*` keys are still English-only in
  Arabic and French. One lab is a complete contribution.
- **Building a planned concept.** Sixteen are catalogued and waiting.
- **Reporting a wrong number.** The most serious kind of bug here, and worth
  reporting even when you are not certain.
